APPLICATION

Settings

Configure identifiers, Copilot provider and Rekordbox paths. Click the ⚙️ button top-right to open the settings form.

Configuration location

Settings are persisted to the secure local folder ~/.config/dj-sync-agent/settings.json with file mode 0600.

Values you can configure here

  • SYNC_AGENT_ID, SYNC_API_URL, SYNC_API_KEY
  • REKORDBOX_DB_PATH, REKORDBOX_DB_KEY, Cipher compatibility (default 4)
  • Copilot provider: OpenAI, Anthropic, OpenAI-compatible
  • COPILOT_API_KEY, COPILOT_BASE_URL, COPILOT_MODEL
  • Intelligence jobs API URL and LOG_LEVEL
💡 Tip: after saving changes, restart DJ Sync Agent so the new settings are picked up by the background services.
